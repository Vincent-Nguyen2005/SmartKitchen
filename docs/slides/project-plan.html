02 · Ranh giới dự án

Phạm vi dự án

Tập trung vào nền tảng số và tích hợp dịch vụ; giới hạn rõ các phần chưa triển khai thực tế.

✓ Trong phạm vi

  • Microservices: Auth, Family, Inventory, Recipe, Meal-Diary, Shopping-List, Payment.
  • API Gateway: định tuyến và xác thực JWT.
  • Ứng dụng React Native / Expo cho Android và iOS.
  • Docker Compose cho môi trường phát triển và tích hợp.

↗ Ngoài phạm vi

  • Thiết bị IoT phần cứng thực tế — chỉ mô phỏng API.
  • Thanh toán trực tiếp qua ngân hàng nội địa — chỉ dùng Payment Sandbox.

Ưu tiên hoàn thiện luồng phần mềm và tích hợp an toàn.
